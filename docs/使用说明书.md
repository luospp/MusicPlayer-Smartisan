## ArtisanMusic 功能使用说明书

应用名称：ArtisanMusic（工匠音乐）
包名：`com.yibao.music`
版本：2.0.0_20250715_sz（versionCode 3）
支持系统：Android 8.0（API 26）及以上，仅 arm64-v8a 架构
应用性质：本地音乐播放器，仿锤子（Smartisan）音乐交互。项目仅供学习，不可商用。
文档对应代码：`future` 分支 HEAD `85d28d0`

---

## 一、这是什么应用

ArtisanMusic 播放的是**你手机里已有的音乐文件**。它本身不提供在线曲库、不能搜索和下载歌曲，所有播放内容都来自系统媒体库（MediaStore）扫描到的本地音频。

联网只用于三件事：

1. 按歌名去 QQ 音乐接口查**专辑封面图**，下载后缓存到应用私有目录。
2. 按歌名/歌手去 QQ 音乐接口查**歌词**（LRC），下载后缓存到本地。
3. 百度统计 SDK 上报匿名使用数据与崩溃信息（首次启动即初始化）。

因此：无网络时，除了封面和歌词会退化为占位图与「暂无歌词」之外，**播放、收藏、歌单、定时等全部核心功能均可正常使用**。

## 二、首次启动

### 2.1 启动页

打开应用先进入启动页，背景是一张随机加载的网络图片（左右可滑动浏览，实际图片池有上千条历史链接，其中多数已失效，显示为占位图）。启动页会同时完成权限申请与本地音乐扫描。

### 2.2 权限申请

| 系统版本 | 申请的权限 | 用途 |
|---|---|---|
| Android 13 及以上 | 允许访问音频（`READ_MEDIA_AUDIO`） | 扫描本地音乐，必需 |
| Android 12 及以下 | 存储读写 | 扫描本地音乐，必需 |

主页还会额外申请：

| 权限 | 用途 | 是否必需 |
|---|---|---|
| 通知（Android 13+） | 通知栏播放控制 | 强烈建议开启，否则锁屏与后台无法控制播放 |
| 图片/媒体（Android 13+）或存储（以下） | 「关于」页设置自定义头像 | 可选，仅彩蛋功能使用 |
| 精确位置 | 无实际用途 | 可拒绝，不影响任何功能 |

> **已知问题**：在 Android 8.0 ~ 12 的设备上，启动页申请的是一个未在应用配置中声明的存储权限，系统会直接拒绝且不弹出授权框，随后只显示「请打允许存储的读写权限，否则无法加载音乐!」对话框，扫描流程无法继续。详见《代码风险与修复清单》P0-04。Android 13 及以上不受影响。

### 2.3 扫描配置

首次启动（或从「关于 → 扫描本地音乐」进入）会弹出「扫描配置」对话框，两个可勾选项：

| 选项 | 效果 |
|---|---|
| 不扫描 60S 以下的歌曲 | 过滤掉时长 ≤ 10.8 秒的音频 |
| 不扫描 1M 以下的歌曲 | 过滤掉体积 ≤ 1 MB 的音频 |

点击「继续」开始扫描，点击「取消」也会以默认配置开始扫描（自动扫描场景下）。

扫描过程中启动页显示进度条与文字「已经加载 N 首本地音乐」，完成后变为「本地音乐加载完成 -_- 共 N 首歌」并自动进入主界面。若一首都没扫到，显示「本地没有发现音乐,去下载歌曲后再来体验吧!」并停留在启动页。

> **提示**：扫描不区分音频类型，通知音、铃声、微信语音等也会一并入库，建议勾选上面两个过滤项。

## 三、主界面

主界面由三部分组成：顶部标题栏、中间内容区（五个标签页）、底部播放控制条。

### 3.1 五个标签页

底部导航栏从左到右：

| 序号 | 标签 | 内容 |
|---|---|---|
| 1 | 播放列表 | 自建歌单管理、收藏列表入口 |
| 2 | 艺术家 | 按歌手分组浏览 |
| 3 | 歌曲 | 全部歌曲，四种排序（**默认停留在此页**） |
| 4 | 专辑 | 按专辑分组浏览，支持列表/平铺两种视图 |
| 5 | 关于 | 设置与工具 |

标签页之间**不能左右滑动**切换，只能点底部导航。

### 3.2 顶部标题栏

- **点击标题文字**：在两种底部控制条样式之间切换（详见 3.3）。
- **编辑 / 完成**：进入或退出多选模式（仅「歌曲」页有效）。
- **删除**：多选模式下删除选中歌曲。

### 3.3 两种底部控制条

这是本应用的一个特色设计，点标题栏文字即可切换：

**锤子风格控制条（默认）**

从左到右：专辑封面缩略图、歌名与歌手、收藏按钮、上一曲、播放/暂停、下一曲，下方是一条可拖动的进度条。点击控制条的空白区域进入播放页。

**QQ 风格控制条**

以卡片形式展示当前歌曲封面、歌名和**一行实时滚动的歌词**，下方是收藏与播放/暂停按钮。这张卡片**可以左右滑动切歌**：向左滑下一曲，向右滑上一曲。

> **已知问题**：QQ 风格控制条的歌词刷新定时器时间单位写错了，会以极高频率刷新，导致明显的发热与掉帧。详见《代码风险与修复清单》P0-06。

> 未播放任何歌曲时，控制条上的按钮点击会提示「请先播放音乐」。

## 四、歌曲页

### 4.1 四种排序

页面顶部有四个分类按钮，点击切换：

| 分类 | 排序规则 |
|---|---|
| 歌曲名 | 按标题首字母 A→Z 排列，`#` 类（非字母数字开头）排在最后，列表滚动时显示吸顶字母 |
| 评分 | 按用户评分从高到低 |
| 添加时间 | 按入库时间从新到旧 |
| 播放次数 | 按播放次数从多到少 |

分类按钮右侧还有一个**随机播放**按钮，点击后从整库随机挑一首开始播放。

### 4.2 列表项

每一行显示：专辑封面、歌名、歌手名。根据当前分类，右侧额外显示评分星星（评分页）或播放次数（播放次数页）。正在播放的歌曲左侧显示蓝色小喇叭图标。

- **点击整行**：从该曲目开始播放，并切换到对应分类的播放队列。
- **点击行末「更多」按钮**：弹出更多菜单（见 4.4）。
- **向左滑动整行**：歌曲页主列表**不支持**侧滑删除。侧滑删除只在专辑/艺术家详情列表、歌单详情列表和收藏面板列表里可用。

歌曲页要删除歌曲请走编辑模式（见 4.3）。

### 4.3 编辑模式（多选）

点标题栏「编辑」，每行左侧出现复选框，可勾选多首；标题栏按钮变为「完成」，并出现「删除」按钮。选中后可执行：

- **加到播放列表**：把选中歌曲批量加入某个自建歌单。
- **删除**：从数据库和磁盘删除选中歌曲。

### 4.4 更多菜单

点任意歌曲的「更多」按钮弹出底部菜单，可用项因入口不同略有差异：

| 菜单项 | 功能 | 状态 |
|---|---|---|
| 加到播放列表 | 把该曲加入自建歌单，可现场新建 | 可用 |
| 加到播放队列 | 插入当前播放队列 | **建设中**，点击提示「建设中 -_-」 |
| 喜欢 | 收藏 / 取消收藏 | 可用 |
| 歌词 | 查看该曲歌词 | **建设中**，点击提示「建设中 -_-」 |
| 定时关闭播放 | 仅在播放页的更多菜单中出现 | 可用 |
| 删除 | 从库中和磁盘删除该文件 | 可用 |

> **删除说明**：删除会先移除数据库记录再删磁盘文件。在 Android 10 及以上，由于系统分区存储限制，**磁盘文件通常删不掉**，结果是应用里看不到了，但文件仍占着空间，重新扫描会再次出现。

## 五、艺术家页与专辑页

### 5.1 艺术家页

按歌手名分组，每项显示：歌手名、歌曲数量、其中一张专辑的封面与名称、年份。点击进入该歌手的歌曲详情列表，可播放全部或单曲操作。

> **已知问题**：列表里显示的「年份」实际取到的是数据库列索引而非真实年份，所以同一页所有条目的年份数值都相同且无意义。详见《代码风险与修复清单》P2-07 第 7 条。

### 5.2 专辑页

按专辑名分组，每项显示：专辑封面、专辑名、歌手、歌曲数、年份。页面顶部还有一个**随机播放**按钮和一个**播放全部**按钮（当前两者行为相同，都是从整库随机挑一首开始播放）。

**两种视图模式**，通过页面顶部的「列表 / 平铺」两个按钮切换：

- **列表模式**：一行一张，信息完整。
- **平铺模式**：网格卡片，只显示封面与专辑名，适合浏览。

两种模式切换时带有**封面形变过渡动画**（当前封面从原位置平滑缩放移动到新布局的位置），动画时长可配置。

点击专辑进入详情，可查看该专辑下的所有曲目并播放。专辑封面若本地没有，会自动联网查询并缓存；**长按专辑封面可查看专辑详细信息弹窗**（发行公司、发行日期等，来自 QQ 音乐接口）。

### 5.3 专辑墙

独立的整屏专辑网格视图，展示全部专辑封面，同样支持联网补图。

## 六、播放列表页（歌单）

### 6.1 歌单管理

页面展示所有自建歌单，每项显示歌单名与歌曲数。

- **新建歌单**：页面顶部入口，输入名称创建。名称不可为空，重名会提示「歌曲已存在」。
- **重命名歌单**：长按或在详情内操作。
- **删除歌单**：弹出确认对话框。
- **下拉刷新**：重新加载歌单列表。

点击歌单进入详情，展示该歌单下的全部歌曲，可播放全部或单曲操作。

### 6.2 收藏列表

从播放列表页进入「收藏」，弹出底部收藏面板：

| 按钮 | 功能 |
|---|---|
| 播放全部 | 从收藏列表中随机挑一首开始播放 |
| 收藏（标题区） | 回到列表顶部 |
| 清空 | 弹出确认框，取消全部歌曲的收藏状态 |

收藏的歌曲在库中以「收藏时间」倒序排列。

## 七、播放页

点击底部控制条进入播放页。这是本应用交互最丰富的页面，模拟黑胶唱机。

### 7.1 唱片与搓碟

页面中央是一张旋转的黑胶唱片，播放时匀速转动（一圈约 15 秒），暂停时停住。

**搓碟手势**：用手指按住唱片沿切线方向拖动，可以像 DJ 一样实时改变播放速度和音调（松手后恢复 1.0 倍速并继续播放）。拖动范围限制在 0.5x ~ 2.0x 之间。手指按下时唱片暂停自动旋转，抬起后恢复；快速甩动会触发惯性旋转动画，随后自动回归匀速。

> **提示**：在 90Hz / 120Hz 高刷屏上，唱片的自动旋转速度会偏快（动画按 60fps 假设计算每帧增量）。

### 7.2 唱针

唱片右上方是一根可拖动的唱针，这是主要的进度控制方式：

- **只有拖动唱头（唱针末端）区域才会响应**，拖动唱针其他部分无效。
- 唱针角度与播放进度一一对应，拖动唱针即可跳转到对应位置，松手后从该位置继续播放。
- 为避免拖到最末端就自动切歌，**唱针最大只能定位到总时长的 97%**，最后约 5% 时长无法通过唱针跳转。
- **把唱针归位（抬离唱片）**：暂停播放，唱针自动回到 resting 位置。
- 播放过程中唱针会随进度实时缓慢摆动。

### 7.3 歌词

点击唱片封面切换到歌词视图，再点一次切回封面。

歌词视图特性：

- 当前演唱行用**大字号高亮**，其余行用小字号，并始终居中显示。
- 随播放进度自动滚动，支持一行歌词过长时自动折行。
- **支持手动上下拖拽浏览**，松手后自动回弹到当前行。

歌词区右上角有三个按钮：

| 按钮 | 功能 |
|---|---|
| 歌词开关 | 在封面视图与歌词视图之间切换（带帧动画） |
| 重新搜索歌词 | 打开歌词搜索页，手动挑选歌词 |
| 删除歌词 | 删除本地已缓存的该曲歌词 |

> **已知问题**：在 Android 10 及以上，「删除歌词」实际删除的是一个不存在的路径，点击后歌词依然存在。详见《代码风险与修复清单》P1-11。

歌词来源与优先级：

1. 播放某首歌时，若本地没有对应歌词文件且当前有网络，**自动联网搜索并下载**。
2. 下载失败或搜不到时显示「暂无歌词」。
3. 若接口返回「此歌曲为没有填词的纯音乐，请您欣赏」，则按纯音乐处理。
4. 歌词文件以 `歌名$$歌手.lrc` 命名缓存在应用私有目录，卸载即清除。

### 7.4 其他控制

| 控件 | 功能 |
|---|---|
| 播放/暂停按钮 | 中央主按钮 |
| 上一曲 / 下一曲 | 两侧按钮 |
| 播放模式 | 循环切换：全部循环 → 单曲循环 → 随机播放 |
| 进度条 | 拖动跳转，左侧显示已播时长，右侧显示剩余时长 |
| 音量条 | 调节媒体音量，与系统音量键双向同步 |
| 屏幕常亮 | 开启后查看歌词时屏幕不灭，最长 30 分钟自动失效 |
| 收藏 | 心形按钮 |
| 收藏列表 | 打开收藏面板 |
| 点歌名 / 歌手名 | 跳转到搜索页，按歌手搜索 |
| 长按封面 | 全屏预览大图，支持双指缩放 |
| 更多菜单 | 加到播放列表 / 喜欢 / 歌词 / 定时关闭播放 / 删除 |
| 左上角下箭头 | 返回主界面 |

> **已知问题**：「屏幕常亮」在离开播放页再回来后，再次点击会崩溃（内部的 WakeLock 引用被置空后未重建）。详见《代码风险与修复清单》P3-06。

### 7.5 定时关闭播放

从播放页更多菜单进入。滚轮选择器提供以下档位：

`正在倒计时` / `无` / `15 分` / `30 分` / `1 小时` / `1 小时 30 分` / `2 小时`

- 选择「无」并点「完成」可取消已设置的定时。
- 设置成功后，对话框顶部实时显示「剩余时间 mm:ss」。
- 倒计时结束会暂停播放并关闭通知栏。
- 若定时已在运行，再次打开对话框时选项列表首项为「正在倒计时」，可看到剩余时间。

> **已知问题**：定时服务不是前台服务，应用退到后台较久后进程可能被系统回收，导致定时静默失效、音乐播放一整晚。详见《代码风险与修复清单》P1-13。

## 八、搜索

### 8.1 本地搜索

从标题栏搜索入口进入。搜索的是**本地曲库**，不是在线曲库。

四个类别标签：

| 类别 | 匹配规则 |
|---|---|
| 全部 | 实际按艺术家精确匹配（见下方说明） |
| 歌曲 | 先按歌名精确匹配，无结果则退化为模糊匹配（包含关键词） |
| 艺术家 | 按歌手名精确匹配 |
| 专辑 | 按专辑名精确匹配 |

输入框**边打字边搜索**，无需点搜索按钮。搜索结果列表项的操作与歌曲页一致（点击播放、更多菜单、侧滑删除）。

输入框下方是**搜索历史**标签云，点击任一标签可快速回填搜索词。

> **已知问题 1**：「全部」类别的实现与「艺术家」完全相同，所以用「全部」搜歌名搜不到结果。详见《代码风险与修复清单》P1-16。
>
> **已知问题 2**：「清空搜索历史」按钮是空实现，点击无反应。

### 8.2 歌词搜索

从播放页歌词区的「重新搜索歌词」进入，也可以在无歌词时长按歌词区进入。

1. 页面已自动填入当前歌曲的歌名与歌手。
2. 可修改后点搜索按钮，请求 QQ 音乐歌词接口。
3. 搜到多个结果时，提示「搜索到 N 个结果 (左右滑动查看多个歌词)」，**左右滑动可预览每一条候选歌词**，右下角显示当前第几条。
4. 点右上角「完成」应用当前预览的歌词：应用会先删除本地旧歌词，再下载选中的歌词并与歌名、歌手绑定保存，随后自动返回播放页并展示歌词。
5. 无结果时显示「没搜索到歌词」。

> **已知问题**：把歌名清空后只填歌手来搜索，会走进一条永远匹配不上的过滤分支，结果必然为空。要用歌手筛选，需同时填写歌名。详见《代码风险与修复清单》P1-16 第 4 条。

## 九、通知栏与锁屏控制

### 9.1 通知栏

播放开始后常驻一条通知（需要通知权限），采用应用自绘的样式，分普通视图与展开的大视图：

| 元素 | 说明 |
|---|---|
| 专辑封面 | 见下方已知问题 |
| 歌名 / 歌手 | 若文件名含 `[mqms2]` 标记会自动拆出歌名与歌手；歌手为 `<unknown>` 时显示为 `Smartisan` |
| 收藏 | 仅大视图有，红心为已收藏 |
| 上一曲 / 播放暂停 / 下一曲 | 三个传输控制按钮 |
| 关闭 | 暂停播放并移除通知，同时停止播放服务 |

点击通知主体回到主界面。

> **已知问题 1**：通知栏封面**永远显示默认占位图**，取真实封面的那段逻辑写反了。详见《代码风险与修复清单》P1-04。
>
> **已知问题 2**：在 Android 8.0 ~ 11 上，通知按钮**每个只能点一次**，之后失效（PendingIntent 用了 `FLAG_ONE_SHOT`）。详见 P1-05。
>
> **已知问题 3**：因为采用自绘通知而非系统媒体样式，Android 13+ 的系统媒体控制中心不会把它识别为媒体播放器，锁屏也没有标准媒体卡片。

### 9.2 锁屏与外部控制

应用注册了 MediaSession，因此支持：

- 锁屏界面显示歌名、歌手、专辑、专辑封面与传输控制。
- 蓝牙耳机线控、蓝牙音箱的播放/暂停/上下曲。
- 拔出耳机（或蓝牙断开）时**自动暂停**播放，避免外放。

### 9.3 音频焦点

- 其他应用（导航、短视频、来电）请求音频焦点时，本应用自动暂停。
- 焦点恢复时自动继续播放。

> **已知问题**：焦点恢复时是无条件继续播放的，也就是说你**手动暂停之后**，如果别的应用释放了焦点，音乐可能自己突然响起来。另外系统要求降低音量（duck）时应用只打了日志，没有真的降低音量，导航播报会被音乐盖住。详见《代码风险与修复清单》P2-14。

## 十、关于页

### 10.1 头像

点击顶部头像可从**拍照**或**相册选择**设置自定义头像，选好后进入系统裁剪界面（1:1，输出 480×480）。

> 头像保存在共享存储目录，在 Android 10 及以上写入会失败；裁剪用的 `file://` URI 在 Android 7 及以上会抛异常。这个功能在新系统上基本不可用。

### 10.2 功能入口

| 入口 | 功能 |
|---|---|
| 扫描本地音乐 | 弹出扫描配置对话框，重新扫描媒体库并把新增歌曲入库、把已不存在的歌曲从库中移除。完成后启动页显示「新增 N 首歌曲」 |
| 备份收藏歌曲 | 把全部收藏歌曲的「歌名 + 收藏时间」写入 `/sdcard/smartisan/music/favorite.txt`，用于卸载重装后恢复 |
| 恢复收藏歌曲 | 读取上述文件，把匹配到的歌曲重新标记为收藏并还原收藏时间 |
| 删除错误歌词 | 扫描歌词目录，删除解析后不足两行的无效歌词文件，完成后提示「错误歌词已删除」 |
| CrashLog | 打开崩溃日志面板，可查看本地保存的崩溃记录并分享出去 |
| 切换语言 | 简体中文 / English，选择后当前页面立即重建生效 |
| 版本信息 | 显示版本名、版本号、项目介绍与开源地址 |
| 分享 | 通过系统分享面板把应用介绍文本分享出去 |
| 项目介绍 | 应用简介文本 |

> **已知问题**：「备份收藏歌曲」在 Android 10 及以上会写入失败，但仍然提示备份完成（假成功）；「恢复收藏歌曲」因此永远提示找不到文件。此外恢复逻辑在解析文件时，遇到不含字符 `T` 的行会崩溃。详见《代码风险与修复清单》P0-14、P1-10。

> **语言切换说明**：语言设置只在 Activity 重建时通过已废弃的 `updateConfiguration` 生效，在 Android 13+ 上可能只有部分界面切换成功，且不会影响通知栏、系统媒体中心等外部展示。另外有 13 处界面文案直接硬编码在布局里，大量提示语（「请先播放音乐」「建设中 -_-」「没搜索到歌词」等）硬编码在源码中，切到 English 后仍显示中文。

### 10.3 隐藏入口

**长按头像**会打开一个「放松一下」图片浏览弹窗，左右滑动浏览随机网络图片。

> **强烈建议移除此功能**：它加载的图片来自代码里硬编码的 1835 条第三方图片直链，其中 1814 条是 HTTP 明文，内容包含大量真人明星照片，来源为堆糖、百度图片、新浪图床等第三方站点，无授权、无出处，存在肖像权与版权风险；且这些链接采集于 2015~2017 年，绝大多数已失效。详见《代码风险与修复清单》P0-12。

## 十一、数据存储位置

| 数据 | 位置 | 卸载后 |
|---|---|---|
| 歌曲库、收藏状态、歌单、评分、播放次数、搜索历史 | 应用私有数据库 `favorite-db`（GreenDAO，schemaVersion 10） | 丢失 |
| 播放位置、播放模式、播放状态、语言、扫描配置、控制条样式 | 应用私有 SharedPreferences `music_config` / `artist_music_setting` | 丢失 |
| 歌词文件 | Android 10+：`Android/data/com.yibao.music/files/lyrics/`；Android 9-：`/sdcard/smartisan/music/lyrics/` | 丢失 |
| 专辑封面缓存 | Android 10+：`Android/data/com.yibao.music/files/songAlbum/`；Android 9-：`/sdcard/smartisan/music/album/`、`/artistImage/` | 丢失 |
| 收藏备份文件 | `/sdcard/smartisan/music/favorite.txt` | **保留**（设计意图如此，但见 P1-10） |
| 崩溃日志 | Android 10+：`Android/data/com.yibao.music/files/crash/`；Android 9-：`/sdcard/CrashLog/log/` | 保留 |

> **注意**：收藏备份的设计目标是「卸载重装后仍能恢复收藏」，但由于 Android 10 引入的分区存储，应用已无权写入共享存储根目录，这个能力在 Android 10 及以上实际已经失效。
